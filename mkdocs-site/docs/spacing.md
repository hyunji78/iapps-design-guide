# Spacing

`space-N = N × 4px` 규칙 (Tailwind 기본 스케일과 동일 수준).

| 이름 | 값 | 주 용도 | 미리보기 |
|---|---|---|---|
| space-1 | 4px | 아이콘-텍스트 최소 간격 | <span class="mini-bar" style="width:4px;"></span> |
| space-2 | 8px | 배지 안쪽 여백 | <span class="mini-bar" style="width:8px;"></span> |
| space-3 | 12px | 컴포넌트 기본 간격 | <span class="mini-bar" style="width:12px;"></span> |
| space-4 | 16px | 인풋/버튼 안쪽 여백 | <span class="mini-bar" style="width:16px;"></span> |
| space-5 | 20px | 상단 영역-타이틀 간격 | <span class="mini-bar" style="width:20px;"></span> |
| space-6 | 24px | 카드 사이 간격 | <span class="mini-bar" style="width:24px;"></span> |
| space-8 | 32px | 섹션 안 블록 사이 | <span class="mini-bar" style="width:32px;"></span> |
| space-10 | 40px | 페이지 상단 여백, 아이콘 버튼 터치 영역 | <span class="mini-bar" style="width:40px;"></span> |
| space-12 | 48px | 카드 그룹 사이, 팝업 안쪽 여백 | <span class="mini-bar" style="width:48px;"></span> |
| space-14 | 56px | 화면 하단 여백 | <span class="mini-bar" style="width:56px;"></span> |
| space-16 | 64px | 랜딩 섹션 사이(기본), 사이드바 축소폭 | <span class="mini-bar" style="width:64px;"></span> |
| space-20 | 80px | 랜딩 섹션 사이(넓게) | <span class="mini-bar" style="width:80px;"></span> |
| space-24 | 96px | 랜딩 히어로 위아래 여백 | <span class="mini-bar" style="width:96px;"></span> |

미세조정 예외(스케일 밖 별도 관리): **2px**(아이콘 내부 정렬), **6px**(타이틀-서브타이틀처럼 붙어야 하는 텍스트 간격)
