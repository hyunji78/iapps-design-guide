### White / Black / Surface

순백(#FFFFFF)·순흑(#000000) 대신 브랜드 톤이 살짝 섞인 값을 지정.

| 이름 | hex | 용도 |
|---|---|---|
| white | #FBFCFF | 화면의 "흰색" 역할 (배경) |
| black | #1A1C20 | 화면의 "검정" 역할 (= gray-1000) |
| surface | #F7F8F9 | 카드/컴포넌트 배경 (= gray-100) |
| surface-accent | #F1F5FE | 강조 섹션 배경 (= primary-50) |
| surface-accent-strong | #DEE8FD | 강조 섹션 배경, 진하게 (= primary-100) |

- gray-0(#FFFFFF)는 스케일엔 남겨두되 실제 화면엔 안 씀 (white 토큰이 대신함)
- surface-accent는 "강조하고 싶은 섹션"에만 제한적으로 사용, 일반 카드에는 중립 surface 사용

### 그림자 색상 매칭 규칙

- 중립/검정 오브젝트 → gray-1000 그림자
- 컬러 오브젝트(버튼 등 작은 요소) → 같은 팔레트의 **900단계**를 그림자 색으로 사용 (opacity는 중립 대비 +10%p)
- 모달/토스트 같은 큰 오버레이는 컬러 그림자 대신 항상 gray-1000으로 통일

### 자간 (국문만 크기별로 조정, 영문/일문은 0)

| 이름 | 자간(국문) |
|---|---|
| Display 0 / 1 | -4% |
| Display 2 / Heading 1 | -3% |
| Heading 2 | -2.5% |
| Heading 3 / 4 | -2% |
| Body Large / Default | -1.5% |
| Body Small / Caption | -1% |
| Label | -0.5% |

- 영문: 0(기본값). 라벨·올캡스에 한해 선택적으로 +2~3%
- 일문: 0(베타구미 원칙), 조정 최소화
- CSS는 `em` 단위 사용 권장 (`letter-spacing: -0.04em`), px 고정 금지 — 크기 바뀌어도 비율 유지되게

| 화면 언어 | 폰트 |
|---|---|
| 국문/영문 | `Pretendard, sans-serif` |
| 일문 | `"Pretendard JP", Pretendard, sans-serif` |

페이지(언어) 단위로 전체 전환, 한 화면에서 두 폰트 혼용 금지.

## 5. International Design (국문/영문/일문)

### 상대적 시간

| 기준 | 국문 | 영문 | 일문 |
|---|---|---|---|
| 매우 짧은 시간 | 방금 전 | Just now | たった今 |
| 분 | 1분 전 | 1min | 1 分前 |
| 시간 | 1시간 전 | 1h | 1 時間前 |
| 일 | 1일 전 | 1d | 1 日前 |

### 날짜

| | Standard | Compact |
|---|---|---|
| 국문 | 2026년 3월 31일 | 3월 31일 |
| 영문 | Mar 31, 2026 | Mar 31 |
| 일문 | 2026年3月31日 | 3月31日 |

### 큰 수 표기

| 숫자 | 국문 | 영문 | 일문 |
|---|---|---|---|
| 12,300 | 1.23만 | 12.3K | 1.23万 |
| 1,230,000 | 123만 | 1.23M | 123万 |
| 123,000,000 | 1.23억 | 123M | 123億 |

### 기타 규칙

- 거리: km 공통 (영문은 타겟 국가에 따라 mi 검토)
- 구간 표기: 하이픈(-)으로 통일 (물결표/en-dash 미사용)
- 일본어 「 」는 괄호 대체가 아니라 강조·인용 전용
- 텍스트 확장 비율(한국어 원문 기준): 10자 이하 150~250%, 11~20자 130~150%, 21~30자 110~130%, 31~50자 90~110%, 51자 이상 80~90%
- 버튼·라벨은 내용 기준으로 늘어나는 구조(고정폭 금지), 긴 텍스트 영역은 wrap 또는 ellipsis 기본 적용

## 6. Elevation (그림자)

| 단계 | 용도 | CSS |
|---|---|---|
| shadow-1 | 살짝 뜬 카드, hover | `0 1px 2px rgba(26,28,32,.06), 0 1px 3px rgba(26,28,32,.08)` |
| shadow-2 | 드롭다운, 툴팁, 팝오버 | `0 2px 4px rgba(26,28,32,.06), 0 4px 6px rgba(26,28,32,.08)` |
| shadow-3 | 모달, 다이얼로그 | `0 4px 6px rgba(26,28,32,.08), 0 10px 15px rgba(26,28,32,.10)` |
| shadow-4 | 토스트, 최상단 알림 | `0 8px 10px rgba(26,28,32,.08), 0 20px 25px rgba(26,28,32,.12)` |

색상 매칭 규칙은 1번 Color 섹션 참고.

### 그라데이션 글로우 (별도 토큰, 장식용 강조 — 랜딩 히어로 CTA 등 제한적 사용)

| 항목 | 값 예시 |
|---|---|
| 도형 크기 | 대상 요소 대비 사방 +8px |
| 그라데이션 | linear 135deg, Primary 400→700 |
| Blur | 10px (Figma "Layer Blur") |
| 불투명도 | 70% |
| 쌓임 순서 | 콘텐츠보다 뒤 (z-index 낮음) |

CSS 구현: 별도 `::before`/wrapper div에 `filter: blur()` — box-shadow는 그라데이션 미지원(Figma Drop Shadow와 동일한 제약). 부모에 `overflow: hidden` 있으면 잘리므로 확인 필요.

## 7. Radius

B2B 톤에 맞춰 과도하게 둥근 형태 지양, 각진 느낌 유지.

| 이름 | 값 | 용도 |
|---|---|---|
| radius-1 | 4px | 배지, 체크박스, 작은 태그 |
| radius-2 | 6px | 버튼, 인풋 |
| radius-3 | 8px | 카드, 드롭다운 |
| radius-4 | 12px | 모달, 바텀시트, 큰 컨테이너 |
| radius-full | 9999px | 필(pill) — 가로≠세로 요소 (버튼, 배지, 토글) |
| radius-circle | 50% | 완전한 원 — 가로=세로 요소 (정사각형 아바타) |

핸드오프 시 "height/2" 값 대신 항상 `9999px`(필) 또는 `50%`(원) 그대로 전달 — 높이가 나중에 바뀌어도 자동으로 형태 유지됨.

## 8. Iconography

- **아이콘 세트**: Tabler Icons (MIT 라이선스, line/filled 쌍 존재, CMS용 아이콘까지 폭넓게 커버)

| 사이즈 | 같이 쓰는 텍스트 | 용도 |
|---|---|---|
| 16px | Caption/Body Small | 인라인 작은 아이콘 |
| 20px | Body Default | 기본 UI 아이콘 |
| 24px | Heading, 툴바 | 강조 아이콘, 단독 아이콘 버튼 |
| 32px+ | — | 빈 상태, 온보딩 장식 |

- 선 굵기: 24px 기준 2px, 16px는 1.5px로 조정
- 색상: 기본 Gray-700(#868B94), 의미 있을 때만 Primary/Negative/Positive/Warning
- 기본은 Line, 선택/활성 상태만 Filled로 전환
- **아이콘 버튼(단독 사용) 터치 영역**: 아이콘 자체는 작아도 클릭 가능 영역은 최소 **40px×40px**(space-10) 확보. 배경이 안 보이는 투명 버튼도 hit area는 동일하게 유지.

## 9. State

색을 새로 만들지 않고, 기존 50~900 스케일에서 단계를 이동하는 방식으로 통일.

| 상태 | 규칙 |
|---|---|
| Default | 기본 단계 (예: primary-600) |
| Hover | 1단계 더 깊게 (primary-700) |
| Pressed/Active | 2단계 더 깊게 (primary-800) |
| Selected(선택 유지) | 배경: surface-accent / 텍스트: primary-600 |
| Disabled | opacity 40%, cursor: not-allowed (컬러 배경 위 사용이 잦아지면 전용 gray 토큰으로 전환 검토) |
| Focus(키보드) | 2px 링(primary-600), 요소에서 2px 띄움. `:focus-visible` 사용 (마우스 클릭 시엔 안 보이게) |

- Hover는 `@media (hover: hover)` 안에서만 적용 (모바일 터치에서 hover 고착 방지)

## 10. Inclusive Design (접근성)

| 원칙 | 내용 |
|---|---|
| 텍스트 대비 | 본문 최소 4.5:1, 큰 텍스트·아이콘 3:1 이상 |

| 키보드 접근성 | 모든 인터랙티브 요소 Tab 접근 가능, 포커스 시 2px 링 |
| 텍스트 확대 대응 | 폰트 크기 rem 단위 사용 |

## 11. Components (v1 — 실제 사용 기준으로 우선 정리, 이후 하나씩 추가)

범위: Core(Button, Input, Badge, Card, Checkbox/Radio, Table 기본형, Modal) + Extended(Tabs, Dropdown, Pagination, Toast, Empty State, Tooltip) 우선, Advanced(날짜 range picker, 리치에디터, 파일업로더 등)는 필요 시 추가.

### Input / Dropdown 트리거

- 높이 40px, Radius 8px(radius-3), 너비는 Fill(가변)
- 패딩: 상하 12px, 좌우 16px
- Default: 배경 White, 테두리 Gray-400
- Focus: 테두리 Primary-600
- Disabled: 배경 Gray-100, 테두리 유지
- 텍스트: Body Default(15px/Regular), Placeholder는 Gray-600

### Checkbox / Radio / Toggle

- Checkbox·Radio 20×20px, Toggle 40×24px
- 색상은 White(#FBFCFF)/Primary-500(#2D70F8)/Gray-400(#DCDEE3) 3가지만 사용
- 선택됨: 배경·링·점 Primary-500, 아이콘/갭 White / 선택 안 됨: 배경·갭 White, 테두리·아이콘·점 Gray-400
- Checkbox는 테두리+배경 위에 체크 아이콘(선택 안 됨일 땐 Gray-400 고스트 아이콘), Radio는 링(4px)+중앙 점 구조
- SVG 기반으로 제작 (PNG 이미지 방식 지양)

### Dropdown 메뉴 패널

- Radius 8px, 배경 White, Effect: shadow-2
- 리스트 아이템: 높이 40px, 좌우 패딩 12px, hover/선택 시 배경 Gray-200

## 12. Voice and Tone

**Role**
- 서비스 사용성: 고객사가 목적을 빠르고 정확하게 달성하도록 돕고, 데이터를 신뢰할 수 있게 전달
- 브랜드 관계: **"함께 성장하는 파트너"** — 우리 툴을 통해 고객사의 비즈니스가 잘 되고 있다는 신뢰를 계속 줌

**Principle**: 명확한, 이해하기 쉬운, 신뢰감 있는

**Voice Tone**: 전문적이면서 친근한

**어투 기준** (B2B라 당근의 "해요체" 기본과 다르게 설정)

| 영역 | 기본 어투 |
|---|---|
| 제안서, 공식 알림, 결제/계약 관련 | 습니다체 |
| 가이드 문서, 대시보드 설명 | 습니다체 |
| 버튼, 툴팁, 빈 상태 문구, 온보딩 팁 | 해요체 허용 |

## 13. Writing

### 전문용어 유지 목록

이탈, 세그먼트, 변수, 리텐션, 전환율, 노출, 발송, 캠페인, 타겟팅, 전환, 유입, 재구매, 트리거 — 서비스 초기부터 써온 CRM/마케팅 표준 용어는 그대로 유지. 새 용어 쓸 때마다 이 목록에 추가.

> **전문용어 유지 원칙**: 용어(명사) 자체는 그대로 두고, 그 용어를 감싸는 조사·어미·설명 방식만 부드럽게 다듬는다. 가능하면 "그래서 어떤 결과가 생기는지"를 한 문장 안에 붙인다.

## 14. 디자인 생성 시 금지사항

지금까지 대화에서 확정된 항목 위주로 정리. 추가할 내용 있으면 이 섹션에 계속 채워나가면 됨.

- 순백(#FFFFFF)·순흑(#000000) 직접 사용 금지 — 항상 white(#FBFCFF)/black(#1A1C20) 토큰 사용
- Gray-0(#FFFFFF)는 스케일 보존용으로만 남기고 실제 화면에는 사용 금지
- 타이포그래피 Black(900) 굵기 사용 금지 — ExtraBold(800)까지만
- Radius 16px 이상 사용 금지(모달 12px가 최대치) — 랜딩/PPT 등 예외 상황 제외
- 그림자 없이 순수 검정(#000) 컬러의 box-shadow 금지 — 항상 브랜드 gray-1000 또는 해당 팔레트 900단계 사용
- 모달/토스트 같은 큰 오버레이에 컬러(그라데이션) 그림자 사용 금지 — 중립 그림자만
- 아이콘 두 세트(예: Tabler + 다른 세트) 혼용 금지
- 색상만으로 상태(성공/실패/경고) 표현 금지 — 아이콘 또는 텍스트 라벨 항상 병기
- 클릭 가능한 아이콘 단독 버튼의 히트 영역 40px 미만 금지
- 국문 이외 언어(영/일)에 국문 자간 값(-1%~-4%) 그대로 적용 금지 — 영/일문은 0 기준
- 체크박스/라디오/토글 등 상태 아이콘을 PNG 이미지로 새로 제작 금지 — SVG 기반만

### AI 생성 느낌 방지 (일반 디자인 규칙)

AI가 생성한 디자인이 흔히 갖는 "티" — 대부분 해외 SaaS 학습 데이터의 평균값이라, 브랜드와 무관하게 반복되는 패턴. 색상 팔레트·폰트 크기 위계·라운드 값·그림자·테두리 두께·대비처럼 이미 저희만의 값이 정해진 항목은 제외하고, 그 외 구조적·장식적 패턴만 금지 목록에 포함.

**색상**
- 브랜드 컬러가 아닌 보라→파랑 계열 그라데이션 배경/버튼 사용 금지
- 다크 배경 + 네온(형광) 글로우 효과 금지
- 배경에 원형으로 퍼지는 라디얼 글로우 금지
- 섹션 뒤 무대조명처럼 퍼지는 스포트라이트 헤이즈 금지

**타이포그래피**
- 제목 위 배경 있는 알약형 "eyebrow" 라벨 금지 (필요하면 텍스트만, 배경 없이)
- 제목 위 대문자를 띄엄띄엄 벌린 kicker 텍스트 금지
- 아이콘을 제목 위에 세로로 쌓는 카드 구조 금지 — 아이콘은 제목 옆에 나란히 배치
- 과도한 이모지 사용 금지 — 아이콘 필요 시 Tabler 라인 아이콘으로 통일
- 한 문장짜리 긴 제목을 화면 전체 크기로 키우는 것 금지
- 한글 제목에 이탤릭 명조체 사용 금지 (한글은 세워서, 영문 혼용 부분만 이탤릭 허용)
- Inter, Geist, Space Grotesk, Instrument Serif 등 한글 미지원 폰트 사용 금지 — Pretendard 고정
- 제목/본문을 굵기만 다른 동일 폰트로 때우는 것 금지 — Display~Label 스케일로 명확히 구분

**카드·박스 UI**
- 카드 왼쪽에 굵은 색상 스트라이프(액센트 보더) 붙이는 것 금지
- 카드 안에 카드를 또 넣는 중첩 구조 금지
- 글래스모피즘(반투명 유리 느낌) 금지 — 실제로 겹치는 요소(플로팅 헤더 등) 예외적 허용
- 장식용 격자(그리드) 배경 무늬 금지
- 반복되는 사선 그라데이션 줄무늬 배경 금지
