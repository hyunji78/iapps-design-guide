# Writing

## 전문용어 유지 목록

이탈, 세그먼트, 변수, 리텐션, 전환율, 노출, 발송, 캠페인, 타겟팅, 전환, 유입, 재구매, 트리거 — 서비스 초기부터 써온 CRM/마케팅 표준 용어는 그대로 유지. 새 용어 쓸 때마다 이 목록에 추가.

> **전문용어 유지 원칙**: 용어(명사) 자체는 그대로 두고, 그 용어를 감싸는 조사·어미·설명 방식만 부드럽게 다듬는다. 가능하면 "그래서 어떤 결과가 생기는지"를 한 문장 안에 붙인다.

## Do / Don't

| 규칙 | ✅ Do | ❌ Don't |
|---|---|---|
| 전문용어 유지 + 서술만 부드럽게 | 이탈한 고객을 다시 데려옵니다 | 이탈한 고객의 재인입을 유도합니다 |
| 존칭어 — 과도한 존대 지양 | 캠페인은 최대 5개까지 등록할 수 있습니다 | 캠페인은 최대 5개까지 등록하실 수 있습니다 |
| 숫자는 아라비아 숫자 | 이번 달 발송 12,480건 | 이번 달 발송 만이천사백팔십 건 |
| 내부 은어·줄임말 지양 | 리텐션율이 지난달보다 올랐습니다 | 리텐이 올랐어요 |
| 기능명보다 목적·결과 | 메시지마다 고객 이름을 자동으로 불러와요 | #USER# 변수를 활용한 고객명 치환 |
| 긍정문 사용 | 캠페인은 한 달에 5개까지 등록할 수 있습니다 | 캠페인은 한 달에 6개 이상 등록할 수 없습니다 |
| 능동문 사용 | 이 리포트는 관리자에게만 보이는 데이터입니다 | 이 리포트는 관리자에게만 보여지는 데이터입니다 |
| 사용자 행위 중심 | 캠페인을 발송했습니다 | 캠페인 발송이 완료됐습니다 |
| 신뢰감 있는 표현(결과를 같이 말하기) | 이번 달 캠페인 전환율은 12%로, 지난달보다 3%p 올랐습니다 | 이번 달 캠페인 성과가 좋습니다 |
| 하나의 목적에 집중 | 문장 하나에 하나의 내용만, 길면 분리 | — |
| 느낌표는 꼭 필요할 때만 | — | — |
| 띄어쓰기 | [발송중] 상태입니다 (상태값은 붙여쓰기) | [발송 중] 상태입니다 |
| | 지금 발송 중입니다 (서술문은 띄어쓰기) | 지금 발송중입니다 |
| 마침표 | 타이틀·버튼·라벨엔 생략, 본문 설명엔 사용 | — |
