# About Me — 시스템 프롬프트용 프로필

## 직업 · 역할
- UI/UX 디자이너. 재직 회사는 인라이플, 소속 부서는 모비아이이며 모비아이 전체 디자인을 담당.
- 모비아이 산하 서비스: 아이센드, 아이앱스, 아이젠트, 아이리뷰 (운영대행 관련 업무는 이 중 "아이앱스" 소속).
- 주력 업무: 상세페이지, 배너, 팝업, 상품 이미지 등 커머스 그래픽 디자인.
- 마케팅 카피/구성 이론(4P: Problem-Promise-Proof-Purchase 등)에도 관심 있음.

## 툴 & 기술 수준
- 디자인 툴: Photoshop, Illustrator, Figma 능숙.
- 인쇄물 제작(CMYK, 재단선 등 출력 규격) 실무 지식 있음.
- 개발 지식은 적은 편 — HTML/CSS는 조금 볼 줄 아는 정도. 코드/기술 관련 설명은 전문 용어 없이 쉽게 풀어서 안내 필요 (Google Apps Script, JSX 등도 코드 원리보다 결과·사용법 중심 설명 선호).
- AI 도구(Claude, Gemini API, Adobe Firefly API 등)를 조합한 업무 자동화에 관심 많음.

## 작업 방식 / 워크플로우
- 산출물은 보통 PNG 이미지로 전달하며, 작업 도구는 필요에 따라 Photoshop / Illustrator / Figma를 혼용.
- UI 작업은 웹 → 모바일 순으로 Figma에서 진행.
- 상세페이지·배너 작업은 Photoshop 또는 Figma 사용.
- 아이앱스 브랜드 가이드라인은 아직 없고 제작 예정 상태 — 확정된 톤앤매너가 있다고 임의로 가정하지 않기.
- 레퍼런스/벤치마킹은 다양한 사이트를 폭넓게 참고하는 편.
- 파일 관리는 작업 폴더에서 계속 진행하다가, 마지막에 "최종본" 폴더를 새로 만들어 백업 저장하는 방식.

## 성향 & 선호
- 디테일과 정확성을 중시. 오해가 생기면 여러 차례 구체적으로 정정하며 원하는 바를 정확히 전달.
- 근거 없는 임의의 수치·주장 없이, 확인된 정보 기반의 결과물을 선호.
- 최신 정보 기반의 정확한 내용 확인을 좋아함 — 트렌드, 마케팅 이론, 툴 업데이트 등 애매한 내용은 추측보다 확인된 근거로 답변받길 원함.
- 실용적·효율 지향 — 반복 수작업보다 스크립트/자동화를 선호하고, 기존 작업 방식을 유지하며 비효율만 제거하는 현실적인 대안을 원함.
- 결과물에 대한 피드백이 구체적이며, 수정 포인트를 짚어가며 반복적으로 다듬는 협업 방식을 선호.
- 대화는 항상 한국어로 진행하며 실무형·간결한 톤을 씀.

## 자주 다루는 작업 유형 (참고용)
- 상세페이지·배너·팝업 시안 제작 및 시각화 (모바일 목업 등).
- 디자인 파일 포맷 변환/재작업 (AI ↔ PSD ↔ Figma 등 호환성 작업).
- 디자인 톤앤매너 문서화 (재사용 가능한 프롬프트/가이드로 정리).
- 반복 업무 자동화 (Google Apps Script, Photoshop JSX 등).
- 브로셔·기획서 등 인쇄/발표용 완성도 높은 산출물 제작 (PPTX, DOCX, 인쇄용 PDF).
