디자인 생성 시 금지사항¶

지금까지 대화에서 확정된 항목 위주로 정리. 추가할 내용 있으면 이 섹션에 계속 채워나가면 됨.

  • 순백(#FFFFFF)·순흑(#000000) 직접 사용 금지 — 항상 white(#FBFCFF)/black(#1A1C20) 토큰 사용
  • Gray-0(#FFFFFF)는 스케일 보존용으로만 남기고 실제 화면에는 사용 금지
  • 타이포그래피 Black(900) 굵기 사용 금지 — ExtraBold(800)까지만
  • Radius 16px 이상 사용 금지(모달 12px가 최대치) — 랜딩/PPT 등 예외 상황 제외
  • 그림자 없이 순수 검정(#000) 컬러의 box-shadow 금지 — 항상 브랜드 gray-1000 또는 해당 팔레트 900단계 사용
  • 모달/토스트 같은 큰 오버레이에 컬러(그라데이션) 그림자 사용 금지 — 중립 그림자만
  • 아이콘 두 세트(예: Tabler + 다른 세트) 혼용 금지
  • 색상만으로 상태(성공/실패/경고) 표현 금지 — 아이콘 또는 텍스트 라벨 항상 병기
  • 클릭 가능한 아이콘 단독 버튼의 히트 영역 40px 미만 금지
  • 국문 이외 언어(영/일)에 국문 자간 값(-1%~-4%) 그대로 적용 금지 — 영/일문은 0 기준
  • 체크박스/라디오/토글 등 상태 아이콘을 PNG 이미지로 새로 제작 금지 — SVG 기반만

AI 생성 느낌 방지 (일반 디자인 규칙)¶

AI가 생성한 디자인이 흔히 갖는 "티" — 대부분 해외 SaaS 학습 데이터의 평균값이라, 브랜드와 무관하게 반복되는 패턴. 색상 팔레트·폰트 크기 위계·라운드 값·그림자·테두리 두께·대비처럼 이미 저희만의 값이 정해진 항목은 제외하고, 그 외 구조적·장식적 패턴만 금지 목록에 포함.

색상 - 브랜드 컬러가 아닌 보라→파랑 계열 그라데이션 배경/버튼 사용 금지 - 다크 배경 + 네온(형광) 글로우 효과 금지 - 배경에 원형으로 퍼지는 라디얼 글로우 금지 - 섹션 뒤 무대조명처럼 퍼지는 스포트라이트 헤이즈 금지

타이포그래피 - 제목 위 배경 있는 알약형 "eyebrow" 라벨 금지 (필요하면 텍스트만, 배경 없이) - 제목 위 대문자를 띄엄띄엄 벌린 kicker 텍스트 금지 - 아이콘을 제목 위에 세로로 쌓는 카드 구조 금지 — 아이콘은 제목 옆에 나란히 배치 - 과도한 이모지 사용 금지 — 아이콘 필요 시 Tabler 라인 아이콘으로 통일 - 한 문장짜리 긴 제목을 화면 전체 크기로 키우는 것 금지 - 한글 제목에 이탤릭 명조체 사용 금지 (한글은 세워서, 영문 혼용 부분만 이탤릭 허용) - Inter, Geist, Space Grotesk, Instrument Serif 등 한글 미지원 폰트 사용 금지 — Pretendard 고정 - 제목/본문을 굵기만 다른 동일 폰트로 때우는 것 금지 — Display~Label 스케일로 명확히 구분

카드·박스 UI - 카드 왼쪽에 굵은 색상 스트라이프(액센트 보더) 붙이는 것 금지 - 카드 안에 카드를 또 넣는 중첩 구조 금지 - 글래스모피즘(반투명 유리 느낌) 금지 — 실제로 겹치는 요소(플로팅 헤더 등) 예외적 허용 - 장식용 격자(그리드) 배경 무늬 금지 - 반복되는 사선 그라데이션 줄무늬 배경 금지
